# Spotify-Platinum

**Next-JS, JavaScript, React/Material UI, Spotify API**

Leveraged Spotify API to create more robust and analytical-driven Spotify application. Developed a comparison feature allowing users to analyze artists side-by-side based on various metrics. Implemented content-based filtering to predict and recommend songs and playlists tailored to user preferences and listening history, enhancing personalization. Designed and created a responsive UI with a real-time music player/visualizer to maximize user experience
